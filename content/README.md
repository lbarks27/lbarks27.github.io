# Content Editing

Portfolio content lives in `content/projects/`.

## Projects
- One file per project in `content/projects/*.md`
- Keep the front matter fields at the top
- Edit the body sections under:
  - `## Overview`
  - `## Solver Deep Dive`
  - `## Data and Results`

## Adding a new entry
1. Create a new Markdown file in `content/projects/`.
2. Add that filename to `content/projects/index.json`.
3. Use an existing file as the template.
